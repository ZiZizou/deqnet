# DEQ-KirchhoffNet Architecture

This document describes the **Deep Equilibrium (DEQ)** extension of KirchhoffNet.
A reader with no access to the codebase should be able to reimplement it to high
accuracy using only this document.

---

## 1. Overview

Replace ODE time-integration `dv/dt = f(v)` with a direct solve for the
fixed-point `f(v) = 0`.  The circuit's right-hand side `f(v)` is strongly
monotone (its Jacobian `J = ∂f/∂v` is symmetric negative definite everywhere),
guaranteeing a unique, globally attracting equilibrium for any input.

### 1.1  What changes vs. ODE mode

| Component | ODE mode | DEQ mode |
|-----------|----------|----------|
| Forward pass | `torchdiffeq.odeint(f, v0, t_span)` | Anderson-accelerated fixed-point `v ← v + β·f(v)` |
| Backward pass | Autograd through ODE solver graph | Implicit Function Theorem: solve `Jᵀ y = ∂L/∂v*` via CG |
| Memory | O(iterations) — stores solver trajectory | O(1) w.r.t. solver iterations — no graph stored |
| Speed | Sequential integration, many steps | Converges in 20–60 iterations |

## 2. Circuit Model (prerequisite)

### 2.1  Topology

A circuit is a directed graph of `E` edges among `n+1` nodes (node 0 = ground).
Each edge connects a source node `sᵢ` to a destination node `dᵢ` (both 1-indexed,
in `[0, n]`).  The edge list is stored as two integer tensors `src_node`,
`des_node` of shape `(E,)`.

Generated by graph functions in `topology.py`:

- `_fully_connect(num_node, repeat=[1,1])` — all-pairs edges (bidirectional).
- `_mix_connect(...)` — CNN-style local connectivity with a fully-connected tail.
- `_neighbor_index(...)` — grid-based nearest-neighbor connections (for images).

All topologies return `(edge_index, cnt)` where `edge_index` is `(E, 3)` with
columns `(src, des, edge_id)`.

### 2.2  Device models (edge conductance)

Each edge `eᵢ` has a monotone activation function `gᵢ(Δv)`.  **Positivity
reparameterization** keeps the slope bounded: `gain = max_gain · sigmoid(raw_gain)`,
so slope ∈ `(0, max_gain)` unconditionally.  Nodal leakage uses
`γ = softplus(raw_γ) + 1e-2`.

Standard devices:
- **Conductance**: `g(Δv) = gain · Δv` (purely linear, SPD Jacobian always).
- **ShiftRelu1**: `g(Δv) = gain · relu(Δv - bias)` — translation-invariant.
- **ShiftLeakyRelu1**: `g(Δv) = gain · leaky_relu(Δv - bias)`.
- **ShiftTanh1**: `g(Δv) = tanh(gain · Δv + bias)`.
- **ShiftRelu2 / ShiftLeakyRelu2 / ShiftTanh2**: `g(v_src, v_des)` depends on
  both nodes independently (not just their difference).
- **Device(negation=True)**: generic wrapper using `g(v_src, v_des)`.

All share the same `max_gain · sigmoid(raw_gain)` reparameterization when
`reparam=True`.

### 2.3  Circuit RHS (the residual function)

The nodal voltage vector `v` has size `n` (non-ground nodes).  Augmented with
a virtual ground node: `v̂ = [0, v]` of size `n+1`.

```
f(v, u) = -Bᵀ · g(B · v̂ ; θ) - Γ · v + S · u
```

where:
- `B` is the incidence matrix of shape `(E, n+1)`:
  - `B[e, src[e]] = -1`
  - `B[e, des[e]] = +1`
- `B · v̂` computes the voltage drop `v_des - v_src` across each edge.
- `g(...; θ)`: per-device activation producing edge current `i_e`.  Returns
  shape `(batch, E)`.
- `Bᵀ · i` sums currents into each node (Kirchhoff's Current Law).
- `Γ = γ·I` is leakage conductance (`γ = softplus(raw_γ) + 1e-2`).
- `S` is an `(n, d_in)` injection matrix: `S[j, k] = 1` if input `k` feeds node
  `j+1`, else 0.
- `u` is the input vector of shape `(batch, d_in)`.

Implementation (in `CircuitLayer.rhs`):

```python
def rhs(self, v, u=None):
    aux_v = torch.cat([zeros_like(v[..., :1]), v], dim=-1)      # (..., n+1)
    i_edge = self.model(aux_v[..., src], aux_v[..., des])        # (..., E)
    result = torch.zeros(..., n+1, device=v.device)
    result = scatter_add(result, -1, src, -i_edge)               # subtract from source
    result = scatter_add(result, -1, des, +i_edge)               # add to destination
    f = result[..., 1:]                                          # drop ground
    f = f - gamma * v
    if u is not None and input_map is not None:
        f = f + u @ input_map.T                                  # inject input current
    return f
```

**Important:** `scatter_add_` (in-place) breaks autograd.  The DEQ code uses
`torch.scatter_add` (out-of-place) for a clean computation graph.

### 2.4  Jacobian structure

The Jacobian of `f` w.r.t. `v` is:

```
J(v) = -Bₙᵀ · D(v) · Bₙ - Γ
```

where `Bₙ = B[:, 1:]` (drop ground column) and `D(v) = diag(g'(B·v̂))` has
diagonal entries `dᵢ(v) ∈ [0, max_gain]`.  Since `Bₙᵀ D Bₙ` is positive
semidefinite (it is a graph Laplacian weighted by D) and `Γ = γ I` is strictly
positive definite, the sum `M = Bₙᵀ D Bₙ + Γ` is SPD.  Therefore:

```
J = -M   is symmetric negative definite (NSD).
```

This is the central property that makes DEQ work: a unique equilibrium exists,
fixed-point iteration converges, and the implicit backward pass is well-conditioned.

## 3. DEQ Solver (`deq_solver.py`)

### 3.1  Fixed-point iteration

Solve `f(v) = 0` by iterating `v ← v + β·f(v)`.  For linear `f(v) = -Mv + b`,
the map `g(v) = (I - βM)v + βb` has eigenvalues `1 - β·λ(M)`.  Convergence
requires `β ∈ (0, 2 / λ_max(M))`.

In practice, the optimal Chebyshev step is `β_opt = 2 / (λ_min(M) + λ_max(M))`.
The solver uses a conservative `β` (often 0.05–1.0) to accommodate nonlinear
devices where `D(v)` changes.

```python
def fixed_point(f, v0, beta, tol, max_iter):
    v = v0.clone()
    for k in range(max_iter):
        fv = f(v)
        res = abs(fv).max()
        v = v + beta * fv
        if res < tol: break
    return v, info
```

### 3.2  Anderson acceleration

Type-I Anderson (also called "Anderson mixing") accelerates convergence by
maintaining a history of the last `m` iterates and residuals.

**Algorithm at step `k`:**

1. Compute `f_k = f(v_k)` and `g_k = v_k + β·f_k`.
2. If `‖f_k‖_∞ < tol`: converged — return `g_k`.
3. Store `g_k` in a ring buffer of size `m`.  Store `f_k` likewise.
4. If fewer than 2 entries stored: `v_{k+1} = g_k` (plain fixed-point step).
5. Otherwise, with `V_0..V_{m-1}` and `F_0..F_{m-1}`:
   - `D_F[:, i] = F_{i+1} - F_0`, `D_V[:, i] = V_{i+1} - V_0`
   - Solve `D_F @ x ≈ -F_0` via `torch.linalg.lstsq` (least squares)
   - `v_{k+1} = V_0 + D_V @ x`
   - Algebraic equivalent of finding `α` minimizing `‖∑ αᵢ Fᵢ‖` with `∑ αᵢ = 1`,
     then setting `v = ∑ αᵢ Vᵢ`.

Implementation uses flattening to 1D and a circular buffer:

```python
V_buf = zeros(m, flat_dim)
F_buf = zeros(m, flat_dim)
head = 0; nstored = 0

for k in range(max_iter):
    fv = f(v); g = v + beta * fv
    V_buf[head] = g.flatten(); F_buf[head] = fv.flatten()
    head = (head + 1) % m;  nstored = min(nstored + 1, m)
    if nstored >= 2:
        F0 = Fs[0]; V0 = Vs[0]
        D_F = (Fs[1:] - F0).t(); D_V = (Vs[1:] - V0).t()
        x = lstsq(D_F, -F0).solution
        v_new = V0 + D_V @ x
        if isfinite(v_new): v = v_new.reshape(original_shape)
```

### 3.3  Contractivity certificate

Because the slope of every device is bounded by `max_slope()`, we can compute
the worst-case `D` at initialization: `D_worst[i] = max_gain[i] / 4` for
sigmoid activations, `max_gain[i]` otherwise.

The function operates on the **stiffness matrix** `M = Bₙᵀ D_worst Bₙ + Γ`,
which is symmetric positive definite.  Its eigenvalues are the meaningful
quantities:

- `lambda_min_M = λ_min(M)` — the **contraction rate**.  Predicts solver
  iteration count and backward CG condition number.  When devices saturate
  into dead zones, `D ≈ 0` and only `Γ` contracts, so `lambda_min_M →
  gamma_floor` and iteration counts blow up — this is the early-warning
  signal for the late-training collapse described in §"known failure modes".
- `lambda_max_M = λ_max(M)` — controls optimal Chebyshev step `β_opt ≈
  2 / (lambda_min_M + lambda_max_M)` for plain fixed-point iteration.
- `lambda_max_J = -lambda_min_M` — closest-to-zero eigenvalue of the
  Jacobian `J = -M`.  Kept for backward compatibility.

The legacy `passive` flag (`lambda_max_J < 0`) is **vacuous as constructed**:
with `γ = softplus(raw_γ) + gamma_floor` and `gamma_floor > 0`, `J` is NSD
by parameterization and `passive=True` unconditionally.  The flag is
retained but `lambda_min_M` is the meaningful number to log and trend over
training.

```python
def check_contraction(src_indices, des_indices, num_nodes,
                      worst_case_D, gamma_diag):
    Bn = build_incidence(src, des)[:, 1:]  # drop ground
    M = Bn.t() @ diag(worst_case_D) @ Bn + diag(gamma_diag)  # SPD
    eigs = eigvalsh(M)
    return {
        'lambda_min_M': eigs.min().item(),
        'lambda_max_M': eigs.max().item(),
        'lambda_max_J': -eigs.min().item(),
        'contraction_margin': eigs.min().item(),
        'passive': eigs.min().item() > 0,  # vacuous: always True when gamma_floor > 0
    }
```

For `n ≤ 128`, the matrix is built explicitly and `torch.linalg.eigvalsh` used.
For larger `n`, power iteration approximates `λ_max`; `λ_min` is approximated
via CG-based inverse power iteration on `M`.

## 4. Implicit Backward Pass

### 4.1  The Implicit Function Theorem

At equilibrium `f(v*, u) = 0`, the sensitivity of `v*` to `u` is:

```
∂v*/∂u = -J⁻¹ · ∂f/∂u    where J = ∂f/∂v|_{v=v*}
```

The loss gradient w.r.t. parameters `θ` (including `u`) is:

```
∂L/∂θ = -yᵀ · ∂f/∂θ      where y solves  Jᵀ y = (∂L/∂v*)ᵀ
```

This avoids backpropagating through the solver trajectory.

### 4.2  EquilibriumSolve (autograd Function)

A single `torch.autograd.Function` encapsulating forward + backward:

**Forward** (`EquilibriumSolve.forward`):

```python
with torch.no_grad():
    v_star, info = anderson(lambda v: rhs_fn(v, u), v0,
                            max_iter=max_iter, tol=tol, **fwd_kwargs)
ctx.rhs_fn = rhs_fn
ctx.v_star = v_star
ctx.u = u
return v_star.detach().requires_grad_(True)
```

**Backward** (`EquilibriumSolve.backward`):

```python
# Solve J^T y = grad_out for y
y = solve_jacobian_transpose(f_at_v_only, v_star, grad_out,
                              tol=backward_tol, max_iter=backward_max_iter)
y = -y  # sign convention: f_.backward(-y) below

# Re-run residual under enable_grad, populate parameter grads
v_ = v_star.detach().requires_grad_(True)
u_ = u.detach().requires_grad_(True)  # if u exists
with torch.enable_grad():
    f_ = rhs_fn(v_, u_)
f_.backward(gradient=y)               # populates .grad on v_, u_, and all
                                      # network parameters via autograd chain
return (None, None, u_.grad, None)    # grads w.r.t. rhs_fn, v0, u, cfg
```

Key detail: `v_` and `u_` are re-computed with `detach` + `requires_grad_`,
not reused from the forward pass.  This ensures the forward solver graph is
never retained.

### 4.3  solve_jacobian_transpose (matrix-free Jᵀ solve)

Two regimes:

**Small (n ≤ 64):** Build `J` explicitly via `torch.autograd.functional.jacobian`,
then solve `Jᵀ y = rhs` via `torch.linalg.solve` (or `lstsq` fallback).

**Large (n > 64):** Conjugate gradient on the normal equation, matrix-free.

The VJP `z ↦ Jᵀ z` is computed by:

```python
def At(z):
    with torch.enable_grad():
        z_in = z.view_as(v_star)
        v = v_star.detach().clone().requires_grad_(True)
        fv = func(v)                              # f_at_v_only
    return autograd.grad(fv, v, grad_outputs=z_in,
                         retain_graph=False)[0].flatten().detach()
```

**Critical observation:** `J = df/dv` is symmetric **negative definite**.
CG requires a positive definite system matrix.  Therefore solve:

```
M y = -rhs    where M = -J = Bₙᵀ D Bₙ + Γ (SPD)
```

```python
M_times = lambda y_flat: -At(y_flat)

y = zeros_like(rhs)
r = -rhs - M_times(y)
p = r
for k in range(max_iter):
    Mp = M_times(p)
    pMp = p @ Mp
    if pMp <= 0: break         # numerically done or M not SPD
    alpha = rs_old / pMp
    y += alpha * p
    r -= alpha * Mp
    rs_new = r @ r
    if sqrt(rs_new) < tol * max(1, ||rhs||): break
    p = r + (rs_new / rs_old) * p
    rs_old = rs_new
return y
```

If CG fails (`pMp < 0` or catastrophic residual growth), fall back to
fixed-point iteration `y ← y + β·(Jᵀ y - rhs)`.

### 4.4  Phantom gradients (biased but robust)

A cheaper alternative: damped fixed-point iteration on the backward pass.

```python
for _ in range(phantom_steps):
    Jty = jt_apply(y)
    y = grad_out - phantom_damp * (Jty - grad_out)
```

This avoids the iterative linear solve entirely, at the cost of biased gradients.
Useful early in training when `J` is ill-conditioned (e.g., MNIST with `beta=1.0`).

## 5. Forward Pass Architecture

### 5.1  CircuitNet (`model.py`)

The main module branches on `mode`:

```python
if mode == 'deq':
    circuit_layer_list = [CircuitLayer(topo, circuit_dict) for topo in topology_list]
    self.circuit = EquilibriumBlock(circuit_layer_list, solver_cfg, input_cfg)

def forward(self, x):
    u = self.encoder(x) if encoder else x
    u = u.detach().requires_grad_(True)   # ensure autograd chain connects
    v_star, middle = self.circuit(u, return_middle)
    out = self.projector(v_star) if projector else v_star
    return out, middle
```

### 5.2  EquilibriumBlock (composed multi-layer DEQ)

**Composed mode**: each `CircuitLayer` solves its own equilibrium
sequentially, but the equilibria are **chained** — layer `k` receives the
equilibrium of layer `k-1` as its injected current, not as initial
condition.  This makes the autograd graph span all layers, so every
layer's parameters receive nonzero gradients.

Layer 0's `input_map` is built from the config's `input_nodes` and has
shape `(n_0, d_in)`.  Layer `k >= 1`'s `input_map` has shape `(n_k, n_{k-1})`
and encodes the inter-layer connectivity — the resistive interface
between the output voltages of one layer and the input currents of the
next.  Default is an identity map for shared node indices (zero-padded if
`n_k > n_{k-1}`, truncated if `n_k < n_{k-1}`).

```python
class EquilibriumBlock:
    def forward(self, u, v0=None, return_middle=False):
        prev = u                       # layer 0 receives external input u
        for i, layer in enumerate(self.layer_list):
            init = zeros(batch, layer.max_node_index)       # init is a speed knob only
            def rhs_fn(v, _u=prev, _layer=layer):
                return _layer.rhs(v, _u)
            prev = EquilibriumSolve.apply(rhs_fn, init, prev, solver_cfg)
        return prev, middle
```

This is the v1 fix for what was previously a degenerate mode: `v_star`
was overwritten each iteration, so layers 0..L-2 were solved and their
outputs discarded — only the last layer's parameters received gradients.
The `test_multi_layer_grad_flows_to_earlier_layers` regression test
guards against this.

**Fused mode** (not yet implemented): `merge_topologies` offsets node indices
of each layer, concatenates edge lists, appends inter-layer edges, and creates
a single `CircuitLayer` that settles as one physical circuit.  The
inter-layer edges used in fused mode are the same data as the
inter-layer `input_map`s installed by `EquilibriumBlock.prepare` in
composed mode.

### 5.3  LinearSolveLayer (SPD building block)

Solves `f(w) = p - R w = 0` where `R` is SPD.  Forward is Anderson; backward
uses the same CG machinery.  This is the core of the streaming RLS demo (not
yet written).

## 6. Training Pipeline (`main_deq.py`)

### 6.1  Config structure (YAML)

```yaml
mode: deq
solver:
  method: anderson                 # anderson | fixedpoint
  tol: 1.0e-5
  max_iter: 60
  anderson_m: 5
  beta: 0.05
  backward_mode: exact             # exact | phantom
  backward_tol: 1.0e-5
  backward_max_iter: 30
fabric:
  gamma_floor: 0.05
  max_gain: 5.0
  input_nodes: [1, 2, 3, 4, 5]
  merge: composed
contract_check_every: 2
network:
  model:
    name: ShiftRelu1
    args: {max_gain: 5.0, reparam: true}
  initialization: kaiming
  net_struct:
    - name: _fully_connect
      args: {num_node: 6, repeat: [4, 4]}
    - name: _fully_connect
      args: {num_node: 6, repeat: [4, 4]}
  # ...
```

### 6.2  Training loop

```python
for epoch in range(num_epoch):
    for inputs, labels in train_loader:
        optimizer.zero_grad()
        outputs, _ = model(inputs)
        loss = criterion(outputs, labels)
        loss.backward()            # triggers EquilibriumSolve.backward
        optimizer.step()

    stats = model.solver_stats()   # n_iter, final_residual per layer
    if epoch % contract_check_every == 0:
        cert = contract_check(model, device)
        print(lambda_max, margin, passive)
```

Stepping `loss.backward()` calls `EquilibriumSolve.backward`, which solves
`Jᵀ y = grad_out` via CG then calls `f_.backward(-y)` on the re-computed
residual.  No solver iterations are stored — memory is O(1) in solver steps.

### 6.3  Contraction certificate at runtime

```python
def contract_check(model, device):
    layer = model.circuit.layer_list[0]
    src, des = layer.src_indices, layer.des_indices
    D_worst = layer.worst_case_D()    # max_slope() per device
    gamma_diag = layer.gamma * ones(n)
    return check_contraction(src, des, n, D_worst, gamma_diag)
```

A passive certificate at initialization (`lambda_max < 0`) guarantees that
the fixed-point map is contractive for any choice of parameters (since gain
only decreases, never increases, from the worst case).

## 7. Key Implementation Traps

### 7.1  scater_add must be out-of-place

`result.scatter_add_(-1, ...)` (in-place) corrupts autograd.  Use
`torch.scatter_add(result, -1, ...)` (out-of-place) returning a new tensor.

### 7.2  Device-param initialization for reparam=True

When `model.reparam=True`, each device stores parameters as `raw_gain`, `bias`,
`raw_gain_src`, `raw_gain_des` — NOT as `model.param`.  `CircuitLayer.__init__`
must explicitly initialize these attributes (not just `model.param`):

```python
if hasattr(self.model, 'param'):
    _init_model_param(net_dict['initialization'], self.model.param)
if getattr(self.model, 'reparam', False):
    for pname in ('raw_gain', 'raw_gain_src', 'raw_gain_des', 'bias'):
        p = getattr(self.model, pname, None)
        if p is None: continue
        if init_keyword == 'kaiming':
            nn.init.kaiming_normal_(p.view(1, -1)); p.data = p.data.view(-1)
        elif init_keyword == 'uniform':
            nn.init.uniform_(p, -0.1, 0.1)
        # etc.
```

Otherwise `raw_gain=0` gives `gain=max_gain/2` everywhere and `bias=0` (no
dead zone), making the circuit purely linear and causing the solver to produce
NaN gradients.

### 7.3  CG must solve M y = -rhs (not J y = rhs)

`J = df/dv = -(Bᵀ D B + Γ)` is symmetric **negative** definite.  CG on `J y = rhs`
fails immediately because `pᵀ J p < 0`.  Solve:

```
M y = -rhs    with M = -J = Bᵀ D B + Γ (SPD)
```

using `M_times = lambda y: -At(y)`.  The `y` variable is identical to `J⁻¹·rhs`.

### 7.4  Forward solver uses no_grad

The forward pass (Anderson or fixed-point) must run under `torch.no_grad()`.
The backward re-computes `f(v*)` under `torch.enable_grad()` to build the
gradient graph — only one evaluation at the fixed point, not the whole
solver trajectory.

### 7.5  Init choice is a speed knob only

Contraction implies a unique equilibrium; the limit of a contractive
fixed-point iteration is independent of the starting point.  Init choice
affects iteration count, never correctness — that was the entire point of
moving input from initial condition to injected current.

Consequences:

- Warm-start across **different inputs** is pointless: the equilibrium
  doesn't depend on `v₀` at all, only on `u`.
- Warm-start across **parameter updates** during training is legitimate
  and useful: the equilibrium shifts continuously, so starting from the
  previous iterate reduces iteration count.
- **Composed mode feeds the previous layer's equilibrium as the next
  layer's input `u`, not as its initial condition** (see §5.2).  Init is
  always `v₀ = zeros(batch, n)`; speed, not correctness, drives any
  decision to change it.

If init ever changes the answer, the solver hasn't converged.

### 7.6  Phantom mode for ill-conditioned early training

When `beta` is too large or `max_iter` too few, the backward CG may struggle.
The phantom gradient (`backward_mode: phantom`) provides a biased but stable
gradient at negligible cost.  Used by the MNIST config.

### 8.1  Solver tests (8 tests)

- Fixed-point converges with error `1.7e-7` (5000 iter, strict tol).
- Unique attractor: 5 random initializations converge to same equilibrium
  (spread `2.7e-8`).
- `solve_jacobian_transpose` returns `A⁻¹ rhs` with error `4.8e-7` for n=4.
- Contraction certificate: passive `λ_max=-1.0` (margin `1.0`).
- Zero-gamma chain graph correctly not certified passive (`λ_max≈0`).
- Lipschitz estimate ~3.0 for `f(v)=3v`.
- `lambda_min_M` tracks `gamma` when D=0 (dead-zone floor case, error `<1e-4`).

### 8.2  Device tests (8 tests)

- All `gain ∈ (0, max_gain)` for `ShiftRelu1`, `Conductance`, `Device(negation=True)`.
- `max_slope()` matches `gain.detach()` for all device types.
- Forward shapes correct (batch, num_edge).
- Translation invariance: `ShiftTanh1(x, x) = ShiftTanh1(x+c, x+c)` (diff `<1e-6`).
- Gradient flows through `raw_gain` to `gain`.

## 9. TODO Items

### 9.1  Fused-mode netlist (high priority)

`merge_topologies` in `topology.py` is a `NotImplementedError` stub.  When
implemented, it should:
- Offset node indices of each layer by cumulative node count of previous layers.
- Concatenate edge lists from all layers.
- Append inter-layer coupling edges.
- Build merged `Γ`, `S`, `input_map`.
- Add `mode: fused` branch to `EquilibriumBlock.__init__` and `forward`.

### 9.2  Inter-layer gradient flow (medium priority)

Currently only the last layer's parameters receive gradients in composed mode
(because every layer sees the same `u` while the chain-of-equilibria is broken).
The v2 design feeds `v_{k-1}^*` as the `u` argument of layer `k` (not just
warm-start init), making the autograd chain differentiable across layers.

### 9.3  Streaming RLS demo (medium priority)

`LinearSolveLayer` is implemented and tested, but the full streaming RLS
adaptive-filtering demo script (`run_rls_demo.py`) does not exist:

```
for (x_t, d_t) in stream:
    R = decay * R + outer(x_t, x_t)     # conductance update (write phase)
    p = decay * p + e_t * x_t           # current-source update
    w = LinearSolveLayer(p, R)          # settle phase (the fabric)
    e_{t+1} = d_{t+1} - w @ x_{t+1}
```

Requires baselines: digital RLS, LMS, analog-LMS first-order fabric.

### 9.4  Jacobian regularizer (low priority)

When ReLU biases push all devices into the dead zone, `D ≈ 0` and only `Γ`
contracts, slowing the solver.  Add `λ·relu(μ(J) + c)` to the loss to keep
effective contraction bounded away from zero.

### 9.5  Device.negation=False branch cleanup (low priority)

~15 lines of dead code guarded by `reparam=False`, kept only for ODE backward
compatibility with a `DeprecationWarning`.  Delete in a cleanup pass.

### 9.6  Fused vs. composed ablation (experimental)

Compare accuracy and iteration count between fused and composed DEQ at matched
parameter count.  Requires items 9.1 and 9.2 above.

### 9.7  CNF / log-density via DEQ (research direction)

The equilibrium map is invertible with `log|det(dv*/du)|` computable via
stochastic trace estimation on `J⁻¹`.  Would enable a pure-DEQ flow model
(currently density tasks use ODE via FFJORD).

### 9.8  End-to-end test for EquilibriumBlock (high priority)

`test_multi_layer_grad_flows_to_earlier_layers` manually chains
`EquilibriumSolve.apply` calls — it tests the mechanism, not the class.
A regression in `EquilibriumBlock.prepare` / `forward` / input_map wiring
would pass silently.  Should add `test_equilibrium_block_2layer` that builds
an `EquilibriumBlock`, calls `prepare`+`forward`, and checks non-zero grad
on layer 0 params.

### 9.9  check_contraction NaN guard for large n (high priority)

When `n > 128`, the inverse-power-iteration fallthrough initialises
`lam_min_M = float('nan')` and the CG loop can break (`pMp <= 0`) before
computing the Rayleigh quotient.  The caller logs `lambda_min(M)=nan` with
no distinct warning.  Should detect the NaN and fall back to
`gamma_diag.min().item()` (the lower bound when `D ≈ 0`).

### 9.10  contract_check multi-layer audit (medium priority)

`main_deq.py:contract_check` hardcodes `layer_list[0]`.  For multi-layer
configs, layers ≥ 1 have their own `gamma` and `worst_case_D` but are never
checked.  Should loop over all layers and log per-layer certificate metrics.

### 9.11  EquilibriumBlock.forward v0 parameter (low priority)

The `v0` argument is accepted but ignored — `init` is always
`torch.zeros(batch, n)`.  Harmless today (init is a speed knob per §7.5),
but if warm-start across training steps is desired, `v0` should be wired
through.  Either remove it from the signature or use it.

### 9.12  Test quality cleanup (low priority)

- `test_linear_solve_layer_matches_direct_solve` has a precision-losing
  `.double()` then `.float()` cast at `test_equilibrium_solve.py:267-268`.
- `test_implicit_grad_matches_unrolled` has a dead `solver_cfg` assignment
  at line 63 (immediately overwritten).
- Large-n (>128) path of `check_contraction` has zero test coverage.
